📝 Blog TADS

Projeto de desenvolvimento de uma aplicação web de blog, desenvolvido durante as aulas do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS).

O projeto foi desenvolvido com foco na prática dos conceitos de desenvolvimento Front-End, componentização, gerenciamento de rotas e construção de interfaces utilizando React.

🎓 Projeto acadêmico desenvolvido em sala de aula com assistência do professor Geovani Succi [(@geovani-succi)](https://www.github.com/geovani-succi)

🚀 Tecnologias utilizadas

* React — Biblioteca utilizada para construção da interface.
* Vite — Ferramenta utilizada para desenvolvimento e build da aplicação.
* React Router DOM — Gerenciamento de rotas e navegação da aplicação.
* Material UI (MUI) — Biblioteca de componentes para construção da interface.
* Emotion — Utilizado pelo Material UI para estilização dos componentes.
* JavaScript / JSX — Linguagens utilizadas no desenvolvimento.
* Oxlint — Ferramenta utilizada para análise e padronização do código.

📚 Objetivo

O objetivo deste projeto é aplicar, de maneira prática, conceitos apresentados durante as aulas de desenvolvimento de aplicações web, utilizando uma estrutura moderna baseada em React.

Entre os conceitos trabalhados estão:

* Componentização;
* Criação de interfaces com React;
* Navegação entre páginas;
* Utilização de componentes prontos;
* Estilização de aplicações;
* Organização de código;
* Gerenciamento de dependências com NPM;
* Execução de projetos utilizando Vite;
* Boas práticas de desenvolvimento Front-End.

⚙️ Como executar o projeto

Pré-requisitos

Antes de executar o projeto, certifique-se de ter instalado:

* Node.js
* NPM

1. Clone o repositório

git clone https://github.com/devayzo/blog_tads.git

2. Entre na pasta do projeto

cd blog_tads

3. Instale as dependências

npm install

4. Execute o projeto em modo de desenvolvimento

npm run dev

Após iniciar o servidor, o Vite disponibilizará o endereço local da aplicação no terminal.

🛠️ Scripts disponíveis

O projeto possui os seguintes scripts configurados:

Comando	Descrição
npm run dev	Inicia o servidor de desenvolvimento
npm run build	Gera a versão de produção da aplicação
npm run lint	Executa a análise do código com Oxlint
npm run preview	Executa uma prévia da build de produção

🧪 Build de produção

Para gerar uma versão otimizada da aplicação:

npm run build

Depois, para visualizar a build localmente:

npm run preview
